📋 STEP 1: Register as Paid Customer (2 minutes)
═════════════════════════════════════════════════════════════════════════════

Run the setup wizard:

    cd /tmp/capta-leads
    node setup-paid-customer.js

Answer the prompts:
    • Email: your@email.com
    • Plan: 2 (Professional) ← Recommended for full access
    • Confirm: yes

✅ You're now registered!


🚀 STEP 2: Start the Server (1 minute)
═════════════════════════════════════════════════════════════════════════════

In your terminal:

    npm start

You should see:
    ✅ Server running on http://localhost:3000
    ✅ All modules initialized
    ✅ CORS enabled


🌐 STEP 3: Open in Browser (30 seconds)
═════════════════════════════════════════════════════════════════════════════

Visit this URL:

    http://localhost:3000

✅ Full CAPTA LEADS app is now running locally!

🆘 Troubleshooting
═════════════════════════════════════════════════════════════════════════════

Server won't start?
  → Check if port 3000 is in use: lsof -i :3000
  → Use different port: PORT=3001 npm start

App says you're not registered?
  → Check file exists: cat paid-customers.json
  → Re-run setup: node setup-paid-customer.js

Features don't work?
  → Try test mode: http://localhost:3000/?test=true
  → Check browser console: Press F12
