⚡ QUICK START (5 MINUTOS)

1️⃣  Crie conta Hunter.io (2 min)
    → https://hunter.io/users/sign_up
    → Confirme email

2️⃣  Obtenha API Key (1 min)
    → Login: https://hunter.io/account/api
    → Copie a chave

3️⃣  Configure seu projeto (2 min)
    
    No terminal:
    
    $ cp .env.example .env
    
    Abra arquivo .env e coloque:
    
    HUNTER_API_KEY=sua_chave_aqui
    
    Reinicie servidor:
    
    $ npm start

4️⃣  Teste! (instantâneo)
    
    → http://localhost:3000/dashboard
    → Clique "🎯 Buscar Leads"
    → Digite: dentista
    → Clique "🔍 Buscar Leads"
    
    🎉 Você verá LEADS REAIS!
