🆘 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❓ "Server won't start"
→ Check if port 3000 in use: lsof -i :3000
→ Use different port: PORT=3001 npm start

❓ "App says I'm not registered"
→ Check file: cat paid-customers.json
→ Re-run setup: node setup-paid-customer.js

❓ "Features don't work"
→ Try test mode: http://localhost:3000/?test=true

❓ "Browser cache issue"
→ Clear cache: Ctrl+Shift+Delete
→ Or use Private/Incognito mode
