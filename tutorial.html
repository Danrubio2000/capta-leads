🎯 Introdução

Bem-vindo ao CAPTA LEADS! Esta é uma solução all-in-one para:

  • Buscar leads qualificados
  • Enviar campanhas de email em massa
  • Criar landing pages sem código
  • Rastrear resultados
💡 Dica: Você pode começar com a versão gratuita e explorar a plataforma sem limites. Os únicos limites são: 100 leads de teste por busca.

O que você vai aprender neste tutorial:

⏱️ Tempo estimado: 30 minutos
Após este tutorial, você saberá usar todos os recursos principais do CAPTA LEADS.

⚙️ Setup Inicial (5 minutos)

Passo 1: Acessar o Console

Abra: http://localhost:3000
Você deve ver um dashboard bonito com 4 seções principais.

Passo 2: Entender as Seções

1. 📊 Dashboard: Vê seus stats (leads, campanhas, emails enviados)
2. 🎯 Buscar Leads: Encontre contatos qualificados
3. 📧 Campanhas: Crie e envie emails
4. 🎨 Landing Pages: Crie páginas de venda
5. ⚙️ Configurações: Email, API keys, etc.

Passo 3: Configurar Email

Vá em: Configurações → Email
Preencha:
- Email de origem (seu email)
- Nome do remetente (seu nome ou empresa)
Resultado: Agora você pode enviar emails de verdade!
✅ Setup concluído! Você está pronto para usar CAPTA LEADS.

🎯 Como Buscar Leads (10 minutos)

Entender a Busca de Leads

O CAPTA LEADS busca leads em múltiplas fontes:

  • Hunter.io: Emails corporativos
  • Clearbit: Dados corporativos
  • Google: Busca web
  • Database Local: 50+ leads verificados

Passo 1: Navegar para Busca de Leads

Clique em: 🎯 Buscar Leads

Passo 2: Preencher Critérios

1. Palavras-chave: O que você procura?
Exemplo: "fundação documentário", "agência marketing", "clínica médica"

2. Localização: Onde? (Ex: Brasil, USA, Internacional)

3. Tipo: Que tipo de negócio?
- Negócio
- Fundação
- ONG
- Qualquer

Passo 3: Clicar em "Buscar"

Aguarde 2-3 segundos. Os resultados aparecem em uma tabela com:
  • Nome da organização
  • Email de contato
  • Website
  • Score de confiabilidade (0-100)

Passo 4: Adicionar Leads à Lista

Para cada lead interessante, clique em: ➕ Adicionar
O lead é salvo em sua lista pessoal.

Exemplo Prático

Cenário: Você é documentarista buscando fundações

Palavras-chave: "documentary grant, film funding"
Localização: International
Tipo: Fundação

Resultado esperado: 20-50 fundações que financiam documentários
✅ Leads encontrados! Próximo passo: enviar campanhas.

📧 Criar Campanhas de Email (10 minutos)

Passo 1: Navegar para Campanhas

Clique em: 📧 Campanhas

Passo 2: Criar Nova Campanha

Preencha:
1. Assunto: Linhas de assunto atraem cliques
Exemplo: "Documentário Sobre Mudanças Climáticas - Busco Parceiros"

2. Corpo do Email: Sua mensagem
Personalize com: {nome}, {empresa}, {email}

3. Email de Origem: Seu email

4. Nome do Remetente: Seu nome ou empresa

Exemplo de Email Efetivo

Assunto: "Parceria para Documentário Premiado - {empresa}"

Corpo:
Olá {nome},

Sou documentarista e meu projeto "Mudanças Climáticas" foi selecionado para Sundance 2026.

Gostaria de explorar uma parceria com {empresa} para financiar a pós-produção.

Podemos conversar essa semana?

Abraços,
[Seu Nome]

Passo 3: Enviar Campanha

1. Clique: "Criar Campanha"
2. Na tabela abaixo, clique: "📧 Enviar"
3. Aguarde: Emails são enviados em 2-3 minutos para todos os leads
4. Veja resultado: Dashboard mostra "Emails Enviados"

Testar Email (Recomendado)

Antes de enviar para todos, teste com sua próprio email:
Seção "Testar Email" → Digite seu email → Clique "🧪 Enviar Email de Teste"
Você receberá o email em segundos para verificar formatting.
💡 Dicas de Assunto Efetivo:
  • ❌ "Olá" (genérico)
  • ✅ "Parceria: Documentário sobre [Tema]" (específico)
  • ❌ "Me patrocine" (direto demais)
  • ✅ "Oportunidade de Impacto Social" (benefício)
✅ Campanha enviada! Próximo: Criar landing pages.

🎨 Criar Landing Pages (10 minutos)

Por que Landing Pages?

Uma landing page profissional aumenta muito a chance de conseguir financiamento. Mostra seriedade e profissionalismo.

Passo 1: Navegar para Landing Pages

Clique em: 🎨 Landing Pages

Passo 2: Criar Nova Página

Preencha:
1. Título: Nome do seu projeto
Exemplo: "Documentário - Mudanças Climáticas"

2. Indústria: Escolha a categoria
- Cinema & Audiovisual
- Arte & Cultura
- Ou outras...

3. SEO (opcional): Para Google encontrar sua página

Passo 3: Adicionar Seções

Após criar, clique "Ver" para editar.

Você pode adicionar seções:
- Hero: Imagem + headline
- Features: Pontos principais
- Testimonials: Críticas
- CTA: Chamada para ação
- Footer: Contato

Exemplo: Landing Page de Documentário

Hero:
Imagem do documentário + "Documentário Premiado Busca Financiamento"

Features:
✓ Selecionado para Sundance 2026
✓ Tema: Mudanças Climáticas
✓ Impacto Social Comprovado

CTA:
"Seja Produtor Executivo - R$50.000+" botão para enviar email

Passo 4: Publicar

Clique "Ver" para gerar URL pública
Copie o link e compartilhe nos emails!
✅ Landing page pronta! Agora comente nos emails.

🚀 Recursos Avançados

Automação de Follow-up

Crie múltiplas campanhas:
- Email 1: Apresentação (dia 1)
- Email 2: Follow-up (dia 3)
- Email 3: Última chance (dia 7)

Isso aumenta taxa de resposta de 5% para 20%!

Integração com APIs

Em Configurações, você pode adicionar:
- Hunter.io: Encontre mais emails
- Clearbit: Enriqueça dados de contatos
- Resend: Envie emails de verdade

Isso potencializa os resultados!

Exportar Resultados

Na seção Leads:
Clique em "📥 Baixar CSV" para exportar para Excel/Google Sheets
