🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❌ Server won't start?
   → Check if port 3000 is in use: lsof -i :3000
   → Kill process: kill -9 [PID]
   → Try different port: PORT=3001 npm start

❌ App won't load?
   → Clear browser cache (Ctrl+Shift+Delete)
   → Check server logs: npm start
   → Try different browser

❌ API returns error?
   → Check .env file exists: ls -la .env
   → Verify API keys are correct
   → Check console (F12) for error messages

❌ Email won't send?
   → Without RESEND_API_KEY, emails are in test mode only
   → Get real key from https://resend.com
   → Add to .env and restart

❌ Language won't change?
   → Clear browser cache
   → Reload page (Ctrl+R)
   → Check browser console for errors
